# Exceptions — ML/AI Technologies That Did Not Fit the Main Table

Every machine-learning / AI technology that shows up in the playlist
(https://www.youtube.com/playlist?list=PLyzTA8cetPdHtlGw1X8Kt7Ea4bd27ApR7) but could not be
given a row in `ml_tech.md`, each tagged `[missing-repo]` or `[repo-moved]`.

- **[missing-repo] Claude Opus 4.1** — Anthropic's Claude models are a proprietary, closed-weight model family with no public GitHub repository of their own; the often-cited `anthropics/claude-code` repository belongs to the separate Claude Code tool, not to the model. Source video: "Claude Opus 4.1 -- The new king of coding?" (https://www.youtube.com/watch?v=VkLByLa5W3k) — Claude is also the incumbent referenced in "Alibaba is coming for Claude..." (https://www.youtube.com/watch?v=-w53i6Ae-YM).

- **[missing-repo] Devstral** — Mistral AI's open-weight agentic coding model is released as model weights on Hugging Face / ModelScope and has no GitHub repository of its own (`mistralai/devstral` returns 404); only unrelated third-party helper repos exist. Source video: "OpenHands + Devstral = A Fully Local Coding Agent" (https://www.youtube.com/watch?v=oV9tAkS2Xic).

- **[missing-repo] GitHub Copilot** — Copilot is a closed commercial product: its first-party GitHub presence is documentation only (the archived `github/copilot-docs` repository) plus per-editor plugins such as `github/copilot.vim`, none of which is a repository of the technology itself. Source video: "Using GitHub Copilot for code reviews: from VS Code to github.com" (https://www.youtube.com/watch?v=xf65vxjNWdk).

- **[missing-repo] OpenAI o1** — o1 is a proprietary OpenAI reasoning model with no public GitHub repository of its own, and "test-time scaling" is a training/inference technique rather than a repository. Source video: "Speculations on Test-Time Scaling (o1)" (https://www.youtube.com/watch?v=6PEJ96k1kiw).

- **[repo-moved] OpenHands** — The repository relocated twice: the project began as OpenDevin at the old location https://github.com/OpenDevin/OpenDevin, was renamed and moved to https://github.com/All-Hands-AI/OpenHands, and the organization was since renamed again so it is now maintained at the new location https://github.com/OpenHands/OpenHands (both older URLs redirect there, and the project is additionally split across several official repos such as OpenHands/software-agent-sdk). Source video: "OpenHands + Devstral = A Fully Local Coding Agent" (https://www.youtube.com/watch?v=oV9tAkS2Xic).
